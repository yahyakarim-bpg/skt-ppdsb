# Dashboard SKT 2027 · PPD Sabak Bernam

Paparan pratonton antara muka Dashboard SKT Pejabat Pendidikan Daerah Sabak Bernam
(Jabatan Pendidikan Negeri Selangor).

**Pratonton:** https://yahyakarim-bpg.github.io/skt-ppdsb/

Halaman ini memaparkan rupa sistem sahaja: halaman alu-aluan, senarai 68 pegawai ikut sektor
dan bot pembantu. Log masuk, SKT, Kalendar Aktiviti dan cetakan PDF hanya berfungsi melalui
web app Google Apps Script yang di-deploy daripada Google Sheet pejabat.
Kod sumber penuh (Code.gs, appsscript.json, ujian) disimpan dalam repo peribadi.
